# Cassidoo Interview Question of the Week Solutions

## Overview

This repository contains my solutions to the **Interview Question of the Week** from the Cassidy Williams newsletter which I really recommend you to check it out through this link:

https://cassidoo.co/newsletter/

I've made a commitment (to myself ofc ^^) to regularly answer these questions to practice my C++ code writing skill and sharpen my understanding on the said language's data structure, algorithm implementation, anddd all the nitty gritty on how C++ works in general.

Each question is organized in its own directory that includes the information related to the question and how I solve it (in a form of a markdown file) + the source code of the final solution implementation.


## Repository Structure
```
question-folder/
├── README.md # Problem description & solution explanation
└── solution.cpp # Implementation
```
